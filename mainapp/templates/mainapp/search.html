How does searching work?
  • Text finds models whose title or description contains the words you entered (case-insensitive).
  • Category restricts results to models the uploader filed under that category. The list shows every category currently in use.
  • Tag restricts results to models tagged with an exact OpenStreetMap-style key=value pair, for example building=yes or man_made=tower. Only the first = separates the key from the value.
  • Filters combine: a model is listed only if it matches all of them.
  • Searches are plain links you can bookmark or share, e.g. /search?query=tower&category=building&tag=man_made=tower.
